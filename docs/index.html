Pse është krijuar SMIP Skill?

Hedhja manuale e 17 orëve javore në regjistrin e SMIP kërkon orë të tëra çdo muaj. Ky skill e zgjidh plotësisht këtë proces.

📅

Kalendari Shkollor & Pushimet

Njeh saktësisht pushimet e dimrit, pranverës, festat kombëtare dhe festat fetare të lëvizshme (Fitër/Kurban Bajrami, Pashkët). Asnjë temë nuk vendoset në ditë pushimi.

📄

Parsim i Planeve Word & PDF

Lexon drejtpërdrejt skedarët e shkarkuar nga Albas, Pegi, Mediaprint, ASCAP apo Smiles. Nxjerr automatikisht titujt e temave dhe situatat e të nxënit.

🤖

Inserim 100% Autonom nga Agjenti

Agjenti përdor Playwright për të lundruar vetë te smip.al, zgjedhur filtrat dhe plotësuar temat njëra pas tjetrës. Nuk kërkohet asnjë veprim manual apo kopjim në Console.

Instalimi me Agjentët AI

Përdoreni këtë skill me Antigravity, Claude Code, Cursor ose nga Terminali.

Google Antigravity (Skill + Chrome CDP / /browser) git clone https://github.com/adalenv/smip-skill.git .agents/skills/smip
Claude Code (MCP Server) claude mcp add smip node ./scripts/smip_mcp.js
Cursor & Windsurf (Native MCP / .cursorrules) Përdor automatikisht .cursor/mcp.json dhe .cursorrules në hapjen e projektit
Google Chrome Direct (CDP Port 9222) node scripts/smip_bot.js --open-chrome --topics temat_tetor_2026.json
